About Live Streaming

This example demonstrates live streaming capabilities. Key features:

  • Automatic M3U8 Probing: The player can probe for M3U8 files at configurable intervals
  • HLS Support: Full support for HTTP Live Streaming (HLS) protocol
  • Live UI: Optimized interface for live content
  • Error Handling: Graceful handling of stream unavailability

Configuration Options:

  • type: 'live' - Enables live streaming mode
  • probeInterval: 5000 - Probe interval in milliseconds (default: 5000)
  • maxProbeAttempts: 12 - Maximum probe attempts (default: 12)
  • onProbeSuccess - Callback when probe succeeds
  • onProbeFailed - Callback when all probe attempts fail

Code Example:

const player = new VSRCPlayer('#live-player', {
    type: 'live',
    mediaId: 'my-live-stream-123',
    probeInterval: 5000,
    maxProbeAttempts: 12,
    onProbeSuccess: (player) => {
        console.log('Stream found and starting playback');
    },
    onProbeFailed: (player) => {
        console.error('Stream not available after all attempts');
    }
});
