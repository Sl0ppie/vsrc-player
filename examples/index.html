Key Features

  • Built on video.js: Leverages the power and reliability of video.js
  • VOD Support: Full support for Video on Demand content in multiple formats
  • Live Streaming: HLS (HTTP Live Streaming) support with M3U8 probing
  • Automatic Probing: Configurable probing intervals for live streams
  • Rich API: Comprehensive JavaScript API for programmatic control
  • Live Chat: WebSocket-based real-time chat with configurable colors
  • Responsive Design: Fluid player that adapts to any screen size
  • Event Callbacks: Custom callbacks for ready, error, probe success/failure
  • Easy Integration: Simple initialization and configuration

Quick Start

To use VSRCPlayer in your project:

<!-- Include the library -->
<script src="dist/vsrc-player.js"></script>

<!-- Create a video element -->
<video id="my-player" class="video-js"></video>

<!-- Initialize the player -->
<script>
  const player = new VSRCPlayer('#my-player', {
    type: 'vod',
    mediaId: 'my-video-123',
    onReady: (player) => {
      console.log('Player ready!');
    }
  });
</script>
