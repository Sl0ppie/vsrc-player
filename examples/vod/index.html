VOD (Video on Demand) Example

Basic VOD Playback

Description: This example demonstrates basic VOD playback using VSRCPlayer. The player is configured to play an MP4 video file.
Status: Initializing...

About This Example

This example shows a basic VOD setup. Key features:

  • Automatic video type detection
  • Standard video controls
  • Programmatic control via JavaScript API
  • Responsive player sizing

Code Example:

const player = new VSRCPlayer('#vod-player', {
    type: 'vod',
    src: 'https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4',
    onReady: (player) => {
        console.log('Player is ready');
    },
    onError: (error) => {
        console.error('Error occurred', error);
    }
});
