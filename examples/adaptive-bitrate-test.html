About Adaptive Bitrate Streaming

Adaptive bitrate streaming automatically adjusts video quality based on:

  • Available Bandwidth: Measured during playback
  • Player Dimensions: Prevents downloading unnecessarily high resolutions
  • Device Pixel Ratio: Accounts for high-DPI displays
  • Network Conditions: Switches to lower quality during congestion

VHS Configuration Options

The following options control adaptive bitrate behavior:

limitRenditionByPlayerDimensions (default: true)

When enabled, the player considers the player size when selecting variants. This prevents downloading a 4K stream for a 480p player, saving bandwidth.

const player = new VSRCPlayer('#my-player', {
    type: 'live',
    mediaId: 'my-stream',
    vhs: {
        limitRenditionByPlayerDimensions: true
    }
});

enableLowInitialPlaylist (default: false)

When enabled, the player starts with the lowest bitrate variant, then adapts upward. This reduces initial buffering time.

const player = new VSRCPlayer('#my-player', {
    type: 'live',
    mediaId: 'my-stream',
    vhs: {
        enableLowInitialPlaylist: true
    }
});

useDevicePixelRatio (default: false)

When enabled, the player considers the device pixel ratio for high-DPI displays. A 540p player on a 2x display will allow 1080p variants.

const player = new VSRCPlayer('#my-player', {
    type: 'live',
    mediaId: 'my-stream',
    vhs: {
        useDevicePixelRatio: true
    }
});

bandwidth

Set an initial bandwidth estimate in bits per second. Useful if you know the user's connection speed.

const player = new VSRCPlayer('#my-player', {
    type: 'live',
    mediaId: 'my-stream',
    vhs: {
        bandwidth: 5000000  // 5 Mbps
    }
});

useBandwidthFromLocalStorage (default: false)

When enabled, bandwidth estimates are persisted in localStorage and reused across sessions.

const player = new VSRCPlayer('#my-player', {
    type: 'live',
    mediaId: 'my-stream',
    vhs: {
        useBandwidthFromLocalStorage: true
    }
});
